# 🎙️ Panduan Voiceover Studio & Script Sheet
**Taman Kata Ajaib × Voice-Storyboard-Video-Tools-Offline (Wedhalabs)**

Dokumen ini memandu Anda membuat file suara berkualitas studio yang jernih, alami, dan ramah anak menggunakan tool offline dari repository [wedhalabs/Voice-Storyboard-Video-Tools-Offline](https://github.com/wedhalabs/Voice-Storyboard-Video-Tools-Offline).

---

## 🚀 Cara Menghasilkan File Suara (.WAV)

1. Buka file **`tools.html`** dari repository Wedhalabs di browser **Google Chrome** atau **Microsoft Edge**.
2. Masuk ke tab **🎙️ Voice Studio**.
3. **Pilih Karakter & Engine**:
   - **Opsi A (Suara Edukator Natural)**: Pilih engine **🇮🇩 AI Indonesia** (Meta MMS-TTS).
   - **Opsi B (Suara Maskot Miko si Kucing Petualang)**: Pilih karakter **Kids / Cartoon** atau gunakan tab **🎭 Voice Changer** dengan preset **Chipmunk** atau **Helium** untuk suara kartun yang menggemaskan!
4. Salin teks dari tabel naskah di bawah, tempelkan ke kolom teks `tools.html`.
5. Klik **▶ Play** untuk mendengar pratinjau.
6. Klik **⬇ Download WAV**.
7. Simpan file `.wav` tersebut dengan nama yang tertera ke folder `assets/audio/` di project Flutter ini.

## ⚡ Bagaimana Jika File Belum Lengkap?
Aplikasi menggunakan **Hybrid Fallback Engine**:
1. Aplikasi mengecek apakah file `.wav` sudah tersedia di `assets/audio/`.
2. Jika **ada**: langsung diputar seketika (0 milidetik, suara studio natural).
3. Jika **belum ada**: otomatis dibacakan oleh mesin TTS bawaan.
Anda bebas menambahkan file suara bertahap sesuai waktu luang Anda tanpa khawatir aplikasi error!
